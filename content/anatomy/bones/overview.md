# Skeleton Overview

---

## Definition

The adult human skeleton has **206 bones**. Textbooks split them into two divisions:

| Division | Count | Role |
|----------|------:|------|
| **Axial skeleton** | 80 | Skull, vertebral column, and thoracic cage — the central axis that protects the brain, spinal cord, and thoracic organs |
| **Appendicular skeleton** | 126 | Pectoral and pelvic girdles plus the upper and lower limbs — attachment and movement |

```
206 = 80 (axial) + 126 (appendicular)
```

## Shape types

Bones are also grouped by shape. Use these labels when filtering the tables in the chapters below.

| Shape | Typical examples |
|-------|------------------|
| **Long** | Humerus, femur, metacarpals, phalanges, clavicle |
| **Short** | Carpals, tarsals |
| **Flat** | Frontal, ribs, sternum, scapula |
| **Irregular** | Vertebrae, sphenoid, ethmoid, hip bone, mandible |
| **Sesamoid** | Patella |

## How to use these notes

1. Open **Axial Skeleton** for the 80-bone inventory (cranial, facial, ossicles, hyoid, vertebrae, ribs, sternum).
2. Open **Appendicular Skeleton** for the 126-bone inventory (girdles and limbs).
3. In each chapter table: sort by column; filter by shape and region; hover a bone name for a Human Atlas still.

Live filtered totals in each table always sum the `count` values of the visible rows, so axial stays at **80**, appendicular at **126**, and the full set at **206**.
